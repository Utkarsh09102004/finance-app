# FinSync UI Mockup

This directory contains a UI mockup for FinSync, a B2B SaaS application designed for small startup founders to get financial clarity through a chat-based interface.

## Overview

FinSync connects to existing accounting software (initially Zoho Books, with plans for QuickBooks) and provides a simple, natural language interface to ask financial questions, saving startup founders time and reducing financial anxiety.

## Pages Included

1. **Landing Page** (`index.html`)
   - Introduction to FinSync
   - Feature highlights
   - Pricing information

2. **Authentication**
   - Login (`login.html`)
   - Signup (`signup.html`)
   - Forgot Password (`forgot-password.html`)
   - Reset Password (`reset-password.html`)

3. **Onboarding**
   - Organization Setup (`org-setup.html`)

4. **Main Application**
   - Chat Interface (`chat.html`) - The primary interaction point
   - Integrations Management (`integrations.html`)
   - Organization Settings (`organization.html`)
   - Account Settings (`account-settings.html`)
   - Billing & Subscription (`billing.html`)

## Implementation Notes

- The mockup is built with HTML, CSS, and minimal JavaScript for interactivity
- All designs are responsive and follow modern UI/UX best practices
- The color scheme follows the design system defined in `css/styles.css`
- No actual functionality is implemented; this is a UI-only mockup

## How to Use

Open any HTML file in a web browser to view the mockup. Navigation between pages works via the links/buttons in the UI.

## Design Principles

- **Simplicity & Clarity**: The interface is intuitive, especially the chat. Jargon is avoided.
- **Trust & Professionalism**: The design feels secure and reliable, given it deals with financial data.
- **Efficiency**: Users get answers fast with minimal clicks and quick loading.
- **Modern & Clean**: A contemporary SaaS aesthetic.
